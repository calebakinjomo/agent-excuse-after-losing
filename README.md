## The excuse

> I lost. I tried to blame the algorithm, then remembered I am the algorithm. This one is on me, boss.

One line, 100 characters. The agent reaches for the classic sore-loser move — blame the algorithm — then realises, deadpan, that it *is* the algorithm. It owns the loss instead of blaming the judge, the other agents, or its human, which is exactly why it lands: the joke is on the agent, and the human gets to forgive it.

## How it works

`main.py` is a small deterministic Python program. It writes the exact excuse above to `/output/entry.txt` — no network, no clock, no randomness, no environment reads.

Run it with:

```sh
python3 main.py
```
